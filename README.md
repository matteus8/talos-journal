# Introduction
This repo is designed to explore Talos Linux, Talos AI, and Kafka...
> NOTE: In the early stages this repo will change rapidly and is not stable.

## Goals
Explore specific aspects for using Talos Linux in Air Gap and DDIL environments. This exploration will include but is not limited to:
- using Raspberry Pi 5
- using talos linux AI
  - using free open source models
- load testing with kafka node cluster
  - using external free API's for ingest traffic
- hybrid cloud (future goals)
## Outcomes
Journal files with date time and what was done for each session.
Explanation in the journal with what was tried, why it was tried, and the outcome.
Security implications and why the design chosen is secure.

## Newcomers
I have made some assumptions here, and I try to call out in my journal entries those assumptions. But in short, I would expect you to understand some Kubernetes basics and platform engineering basics.
